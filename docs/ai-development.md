# AI-Assisted Development

## Tools

- Kiro
- Google Antigravity

## Usage principles

AI was used for:
- requirements refinement
- architecture brainstorming
- implementation assistance
- test generation
- code review
- edge-case discovery

AI-generated code was reviewed and validated manually.

## Workflow

1. Define requirement
2. Ask AI to propose implementation
3. Review design
4. Implement incrementally
5. Run tests
6. Review generated code
7. Refactor where required
8. Commit
